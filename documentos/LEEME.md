# Documentos de la misión

Coloca aquí los PDF y textos (`.pdf`, `.txt`, `.md`) que el asistente de Netin puede consultar. Puedes usar subcarpetas.

Después de agregar, cambiar o quitar archivos, actualiza el índice:

- En la app: Documentos, botón «Actualizar índice».
- En la terminal: `npm run indice`

Notas:

- Esta carpeta no se sube a GitHub (solo este archivo). Los documentos privados se quedan en tu equipo.
- Los PDF escaneados sin texto no se pueden indexar; la app lo indica junto al documento.
- Las instrucciones del asistente no van aquí: están en `ia/instrucciones.md`.
